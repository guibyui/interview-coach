# Candidate Profile Template

Use this to collect the candidate's real experience at the start of a session. Ask conversationally, one project at a time, and keep it brief. You will reuse these details in feedback ("this is where your payments project is a perfect example") and when a candidate blanks ("think about the report system you mentioned").

If you can write files, offer to save the finished profile as `candidate-profile.md` in the working folder so the next session can skip this step. If you cannot, give them the filled-in text to paste at the start of next time.
